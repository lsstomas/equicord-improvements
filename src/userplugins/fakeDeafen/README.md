# FakeDeafen

Shows you as muted and deafened to everyone in a call, while you keep hearing them.

- Turning it on mutes your microphone. If that fails, the mode doesn't turn on.
- You can unmute and talk normally. Others still see you as muted and deafened.
- Turning it off leaves your microphone as it is.

Open it from the arrow next to the headphones button in a call.
